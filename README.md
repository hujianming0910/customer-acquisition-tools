# 客户获取工具库 · Customer Acquisition Tools

> 免费 / 开源 / 可持续维护的获客工具地图。  
> 目标不是“收藏很多项目”，而是让工程商、终端客户开发这条线**少造轮子、快速试对工具**。

仓库地址：<https://github.com/hujianming0910/customer-acquisition-tools>

## 这个仓库是什么

- 一个面向工业控制、西门子 PLC、自动化工程商与终端客户的**工具选型目录**。
- 只收录能用于：找客户、整理线索、建 CRM、做官网承接、内容获客、自动化、数据清洗、网站分析的工具。
- 每个工具都记录：用途、Stars、最近提交、License、免费方式、部署方式、中国网络可用性、合规风险、推荐级别。
- 由牛牛定标准与审核，豆包分批搜索候选，牛牛复核后入库，智能助手同步展示。

## 这个仓库不是什么

**绝对不要放进来：**

- 客户名单、联系人电话、微信、邮箱、询盘记录、聊天记录
- 实价、底价、报价单、供应商价格、内部成本
- API Key、账号密码、Cookie、Token、SSH 私钥
- 公司内部台账、合同、发票、发货信息
- 任何侵犯隐私、绕过平台登录、批量骚扰、钓鱼或规避风控的脚本

这里是**公开工具目录**。业务数据留在本地智能助手和内部系统，不进公开仓库。

## 推荐级别

| 级别 | 含义 | 使用建议 |
|---|---|---|
| **P0** | 场景高度匹配、维护活跃、免费可落地 | 优先试用，2 周内做一次小验证 |
| **P1** | 有价值，但部署或合规需额外评估 | 放进备选池，按需评估 |
| **P2** | 可用但偏重、偏旧或场景较窄 | 观察，不作为首选 |
| **拒绝** | 停更、空壳、许可不清、违规采集 | 不入库，只在淘汰记录里留原因 |

> P0 不等于“马上全量部署”。P0 只是“值得先花时间验证”。每个工具先做 30–60 分钟最小验证，再决定是否进入日常流程。

## 收录硬标准

1. **免费可用**：完全开源可自托管，或有明确免费额度；收费试用伪装免费的不收。
2. **维护活跃**：优先最近 6 个月有提交；超过 12 个月无提交降级；归档项目拒绝。
3. **许可清楚**：MIT、Apache-2.0、BSD、GPL、AGPL 等可识别；许可不明先标“待核实”，不直接推荐。
4. **场景真实**：能落到工程商/终端客户开发的具体动作，不是泛泛的“增长工具”。
5. **数据可控**：优先可本地/自有服务器部署；强制上传客户数据到不明服务的不收。
6. **合规经营**：不收录绕过登录、破解验证码、批量骚扰、钓鱼、爬取非公开个人信息的工具。
7. **证据可查**：Stars、最近提交、License、Release 必须有 URL 和核查日期，不许凭印象填。

详细评分见 [CONTRIBUTING.md](CONTRIBUTING.md)。
